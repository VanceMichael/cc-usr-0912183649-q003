# 人形机器人技能包兼容登记簿

记录技能包、设备构型、标定证书和验证运行。工程目前提供可运行的后端入口和领域配置，后续业务模块应保持传输、领域与持久化职责分离。

## 本地运行

```bash
docker build -t robot-skill-registry .
docker run --rm -p 8080:8080 robot-skill-registry
```

服务就绪后，`GET http://localhost:8080/health` 返回服务标识与状态。

## 开发约定

- 所有业务能力通过后端接口或自动化测试验证。
- 配置中的领域词汇用于统一接口和日志命名。
- 凭据、本地数据文件以及未经处理的敏感字段不得提交到仓库。

## 领域词汇

- 技能包：业务处理的主要输入。
- 设备构型：连接事实与判定过程的记录。
- 验证证书：供查询、审计或持久化使用的结果。
